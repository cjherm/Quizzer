RULES
- 2 to 4 answers per question; at least one correct. One, several or all may be correct.
- Mix: about 2/3 with one correct answer, 1/3 with several (occasionally all).
- Wrong answers must be plausible (typical misconceptions), not silly.
- Answer texts within a question must be unique; keep answers short (max ~15 words).
- Every question gets an "explanation" that also teaches something.
- Only state facts you are confident about. Name the version where it matters
  (e.g. "since Android 13", "in Gradle 8"). If something is version-dependent or
  disputed, rephrase or leave it out.
- No duplicate questions.
- For mode B: output ONLY the new questions, as a JSON array I can append to the
  END of the existing "questions" list. Never reorder, delete or insert in the
  middle: the app stores learning history by question position.

OUTPUT
1. The JSON in one code block (complete file for mode A, array of new questions for mode B).

2. Below it, a short list of questions where you were less than certain, so I can check them.
